# Master Workflow & AI Ecosystem Guide

A breakdown of every tool, software, AI agent, and open-source repository in your stack—organized by workflow phase with practical usage patterns.

---

## 1. UI & Visual Design Stack

| Tool | Focus Area | Why & When to Use It |
|---|---|---|
| **Watermelon.UI** | Component & Design Systems | Quick reference for clean, modern layouts and UI patterns. |
| **Variant** | Design exploration & variants | Testing layout variations and typographic contrast. |
| **GrayBlocks** | Wireframing & Structural layout | Rapidly sketching out content flow before styling. |
| **Mockuply** | High-fidelity device frames | Putting real screenshots into clean, minimal browser/device mockups without cheesy 3D distortions. |
| **Appshots** | App store & portfolio presentation | Crisp asset export for web and mobile portfolio items. |

## 3. Autonomous Agents & AI Coding
